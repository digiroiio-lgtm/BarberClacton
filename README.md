# Turkish Barber Clacton Website

Production-ready Next.js App Router website for **turkishbarberclacton.com** focused on local SEO and WhatsApp conversions.

## Tech
- Next.js (App Router) + TypeScript
- Tailwind CSS
- Vercel-ready deployment

## Run locally
```bash
npm install
npm run dev
```

## Quality checks
```bash
npm run lint
npm run build
```

## Content/config editing
Update central business and SEO content in:
- `src/data/site.ts`
- `src/data/content.ts`
